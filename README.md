# 台灣縣市大戰

仿《都道府縣大戰》(Great War of Prefectures) 的台灣版：22 縣市（含澎湖、金門、馬祖）互相攻伐，統一全台。

## 執行

純前端，不需安裝。在專案資料夾啟動任一靜態伺服器：

```bash
python3 -m http.server 8123
```

然後打開 http://localhost:8123

## 玩法

- **選縣市出征** 或 **觀戰模式**（22 縣市 AI 大亂鬥）
- 每天收稅（萬元），佔滿整個地區（北／中／南／東／離島）有額外稅收
- 點自己的縣市招兵；每縣市每天可出兵一次 → 點相鄰敵方縣市進攻、點己方縣市調兵
- 兵種相剋：🛵 機車 > 💣 砲兵 > 👺 八家將 > 🪖 阿兵哥 > 🛵 機車
- 研發：軍事訓練（攻）、城防工事（防）、經濟發展（稅收）
- 隨機事件：颱風、地震、選舉、媽祖遶境…

## 檔案

- `js/data.js` 縣市資料、相鄰關係、兵種、地區
- `js/map.js` SVG 地圖（Voronoi 拼出近似縣市形狀）
- `js/game.js` 回合流程、戰鬥、AI、介面
- `assets/characters/` 台南、台中、花蓮角色插畫
- `assets/units/` 四種基本兵種角色圖

## 22 縣市大亂鬥（單檔模擬器）

`taiwan-battle-royale.html` 是獨立的單一 HTML 檔，直接用瀏覽器打開即可（不需伺服器、不需網路）。

- 真實台灣縣市邊界地圖（[taiwan-atlas](https://github.com/dkaoster/taiwan-atlas)，MIT；已簡化並內嵌）
- 每回合隨機抽一個縣市勢力攻打相鄰敵人，勝者吞併敗者全部領土；離島只能透過海路連到港口縣市
- 22 縣市角色設定：稱號、四維（經濟／武力／防禦／神秘度）、被動天賦、必殺技、宿敵與羈絆（點地圖查看）
- 20% 機率觸發台灣迷因事件（颱風假、行人地獄、高架橋迷宮、護國神山乖乖…）
- 戰略要地：新竹市「晶片科技霸權」連動兩次、南投「內陸核心」、台北「首都光環」等
- 特殊勝利：集齊六都並守住 5 回合「六都制霸」
- **戰鬥模式**：選一個縣市親自上陣，每回合點相鄰敵方縣市進攻、自選進攻必殺技（冷卻 3 回合），一塊一塊爭奪領土；防守必殺自動發動，越大越會被圍剿
- **觀戰模擬**：AI 自動對戰，勝者吞併敗者整個勢力
