# 台灣縣市大戰

仿《都道府縣大戰》(Great War of Prefectures) 的台灣版：22 縣市（含澎湖、金門、馬祖）互相攻伐，統一全台。

## 執行

純前端，不需安裝。在專案資料夾啟動任一靜態伺服器：

```bash
python3 -m http.server 8123
```

然後打開 http://localhost:8123

## 玩法

- **選縣市出征** 或 **觀戰模式**（22 縣市 AI 大亂鬥）
- 每天收稅（萬元），佔滿整個地區（北／中／南／東／離島）有額外稅收
- 點自己的縣市招兵；每縣市每天可出兵一次 → 點相鄰敵方縣市進攻、點己方縣市調兵
- 兵種相剋：🛵 機車 > 💣 砲兵 > 👺 八家將 > 🪖 阿兵哥 > 🛵 機車
- 研發：軍事訓練（攻）、城防工事（防）、經濟發展（稅收）
- 隨機事件：颱風、地震、選舉、媽祖遶境…

## 檔案

- `js/data.js` 縣市資料、相鄰關係、兵種、地區
- `js/map.js` SVG 地圖（Voronoi 拼出近似縣市形狀）
- `js/game.js` 回合流程、戰鬥、AI、介面

## 22 縣市大亂鬥（單檔模擬器）

`taiwan-battle-royale.html` 是獨立的單一 HTML 檔，直接用瀏覽器打開即可（不需伺服器、不需網路）。
每回合隨機抽一個縣市勢力攻打相鄰敵人，勝者吞併敗者全部領土；20% 機率觸發台灣在地梗事件（慶記支援、全糖護盾、苗栗國結界…）。離島只能透過海路連到港口縣市。
